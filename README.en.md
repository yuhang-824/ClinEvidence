# ClinEvidence

ClinEvidence is an interview-oriented clinical evidence and medical-record quality-control project built on [Yuxi](https://github.com/xerrors/Yuxi).

**Status: branding and implementation planning.** This repository includes the upstream general-purpose platform. Patient snapshots, medical evidence tools and quality-control workflows are planned, not validated clinical capabilities.

See the [Chinese README](README.md) for setup, the [implementation roadmap](docs/develop-guides/clinevidence-roadmap.md) for staged acceptance criteria, and the [validation record](docs/develop-guides/clinevidence-bootstrap-validation.md) for actual checks and limitations.

The internal `yuxi` package, CLI, configuration identifiers and storage contracts remain unchanged. The inherited [MIT license](LICENSE) and upstream copyright are preserved. Patient records, credentials and private evaluation data are not distributed with the code.
