# ClinEvidence 循证医助

基于 Yuxi 的诊疗辅助与病历质控开发项目。当前完成项目命名与开发计划，医疗功能按阶段实施，尚未形成临床验证结论。

从[秋招开发阶段计划](./develop-guides/clinevidence-roadmap.md)查看任务、产物和验收门槛，从[初始化验证记录](./develop-guides/clinevidence-bootstrap-validation.md)查看已执行检查。部署操作以[项目 README](https://github.com/yuhang-824/ClinEvidence#readme)为入口。

其余教程与机制资料继承 Yuxi，用于解释基座已有能力。文档中的上游版本、历史决定与 CLI 名称保留来源，不表示医疗功能已实现。项目保留 Yuxi 的 MIT 许可证和版权声明。
