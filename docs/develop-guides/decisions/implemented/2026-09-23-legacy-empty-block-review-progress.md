# 历史空文块不阻断其他页面保存

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/knowledge/structure.py

## 问题

旧版解析稿中仍有未排除的空正文或解析器占位文块。结构审核每次保存会发送全篇结构，原先前端逐块校验和后端校验要求全篇立即完整，导致审核者即使只核验当前页，也必须先处理其他数十页的文块；保存无法成功，因此保存后的自动翻页也不会执行。

## 决策

保存前仅要求当前页的文块满足正文或排除说明规则。后端在草稿保存时允许原稿中未改动的空正文和占位文块暂存，并在草稿正文中跳过它们；新补录或已修改的文块仍不得以空正文或占位文案参与检索。审核通过与入库继续拒绝任何尚未处理的非排除文块。[逐页导航](./2026-09-23-structure-review-save-navigation.md)只在保存成功后执行。

## 替代方案

首次保存时批量把全篇空块与占位块设为排除：会替审核者对尚未阅读的原页作出判断。仅缩小前端校验范围：后端仍会在全篇修订或正文组合时拒绝保存。

## 后果

审核者能逐页保存并继续核验。草稿正文暂时不包含尚无实际内容的历史文块，但结构记录仍保留原文块及来源；补充原文或明确排除后才可通过最终审核。页面外新产生的空正文或占位文案不会借暂存规则通过后端保存。

## 验证

源码检查：前端保存前只检查当前页，审核前仍检查全篇；`revise_structure` 只放行原稿未改动的空块或占位块，草稿组合跳过它们；`require_structure_review` 拒绝占位块并以严格组合拒绝空块，审核及入库不能通过未处理内容。`docker compose exec -T web pnpm run lint:check` 与 `docker compose exec -T web pnpm run build` 通过；`git diff --check` 通过。后端 Ruff 在容器中缺少可执行文件，尝试安装时因容器内文件权限不足失败。自动化测试未执行，因为本次请求未要求测试。真实审核页仍需登录会话确认。
