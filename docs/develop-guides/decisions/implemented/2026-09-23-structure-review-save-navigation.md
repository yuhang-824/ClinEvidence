# 结构审核保存后顺序进入下一页

状态：implemented
类型：bug-fix
Owner：web/src/components/knowledge/StructuredDocumentReview.vue

## 问题

逐页审核保存后只查找未核验页。后续页面已有机器或人工核验结果时，页面停在原处；双栏仍保留滚动位置，也使切换后的内容不易察觉。

## 决策

保存成功后顺序进入文档的下一页，不依据核验状态跳页。切页时将源页和文块列表滚回顶部。最后一页没有下一页，保存后明确提示已到末页。保存失败时保留当前页和未保存内容。此处替代[审核版本决策](./2026-09-20-review-draft-versioning.md)中的环形查找规则，不改变其版本和并发保护语义。

历史空文块导致保存前失败的问题由[草稿渐进核验](./2026-09-23-legacy-empty-block-review-progress.md)处理。

## 替代方案

继续只找未核验页，并在全部核验后停留：不能满足保存后进入下一页的审核动线。环形跳到第一页：末页保存后会离开当前位置，难以判断是否已经审核完全文档。

## 后果

用户可依原文顺序逐页核对，包括已经自动核验的页面。已核验页不会被自动略过；需要快速定位待核验页时，仍可使用页码选择器。

## 验证

源码检查：保存成功后由面板调用编辑器的 `goToNextPage`；该方法选取当前页后的相邻页面，切页会重新加载源 PDF 并重置双栏滚动位置。末页返回空值，面板显示末页提示。`docker compose exec -T web pnpm run lint:check` 和 `docker compose exec -T web pnpm run build` 已通过。自动化测试未执行，因为本次请求未要求测试。浏览器当前只显示登录入口，无法进入实际审核页确认跳转和截图。
